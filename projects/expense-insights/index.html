PROJECT / DATA EXPLORATION

Personal Expense Insights

See where your money goes. Load a CSV to explore your own expenses, or start with the included example.

THE CHALLENGE

Make spending easier to inspect

A transaction list alone makes it difficult to spot how spending changes across months or which categories account for the most.

THE APPROACH

Keep analysis local and practical

I built a browser-only dashboard with CSV review, editable transactions, month and category summaries, and optional device-local saving.

KEY DECISION

No server or chart dependency

CSV data stays in the browser; built-in HTML and CSS render the visuals. Saving is opt-in so private financial data is not kept automatically.
