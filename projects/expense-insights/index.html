PROJECT / DATA EXPLORATION

Personal Expense Insights

See where your money goes. Load a CSV to explore your own expenses, or start with the included example.

THE PROJECT

What I built

A browser-based expense dashboard that summarizes transactions by category and month, with totals, transaction counts, and average spending.

THE TOOLKIT

Tools used

Built with HTML, CSS, and JavaScript. It uses browser file APIs to read CSV data locally and creates charts directly in the page without a charting library.

THE PRACTICE

What I practiced

The project let me practice CSV parsing, validating user data, aggregating values, formatting currency, and updating a dashboard while keeping imported files on the user's device.

Download sample CSV
