C Programs.

A collection of small terminal programs built while learning and practicing C, from everyday utilities to interactive games.

THE PROJECT

What I built

This collection includes calculators, date and number tools, text utilities, simple trackers, and terminal games such as Hangman, Tic-Tac-Toe, and Rock Paper Scissors.

THE TOOLKIT

Tools used

The programs are written in C using the standard library, compiled with GCC, and designed to run in a terminal.

THE PRACTICE

What I practiced

Building them gave me practice with functions, loops, conditionals, arrays and strings, input validation, file handling, and working with dates and time.
