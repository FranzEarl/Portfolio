THE PROJECT

What I built

A student performance dashboard that imports course data from CSV and summarizes grades, attendance, and study hours across any number of courses.

THE TOOLKIT

Tools used

Built with HTML, CSS, and JavaScript. CSV files are processed locally in the browser, with native DOM and CSS visualizations and no charting dependencies.

THE PRACTICE

What I practiced

I practiced parsing and validating CSV data, calculating summary metrics, rendering accessible charts and tables, and testing invalid input without losing the current dashboard.
